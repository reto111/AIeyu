# Student Web Prototype

> 本文档记录 AIeyu 学生端本地网页原型。
> 当前版本用于验证学习闭环体验，不是最终商业化前端。

## 1. 当前定位

当前学生端原型只面向学生使用，不包含教师端。

已支持：

- 查看已审核题库概况。
- 本地学生账号分离，可新增学生并切换当前学生。
- 学生账号放在默认练习页顶部，方便进入页面后先确认当前学生。
- 错题本保留为独立页面，不堆在练习页内。
- 新用户可一键开始 30 题入门诊断。
- 入门诊断覆盖语法、文学、国情和阅读四类题型，并尽量均衡抽题。
- 显示四类题型掌握度：掌握分、状态标签和累计作答次数。
- 支持从能力画像中一键选择“只练此类”。
- 按题型选择练习范围。
- 按年份选择练习范围。
- 设置题目数量。
- 随机生成俄语专八练习，默认不包含阅读题。
- 随机组卷已接入题目曝光记录，优先未做题和需要回流的旧错题，降低近期做对题重复出现概率。
- 页面作答。
- 提交后自动批改。
- 显示正确率、错题和薄弱知识点。
- 批改后更新本地默认学生的题型掌握度、知识点掌握度和下一步弱项训练建议。
- 批改后按当前学生写入作答记录、题目曝光记录、能力画像和 AI 对话记录。
- 错题本按当前学生汇总曾经答错过的题，并区分“待巩固”和“已订正”；支持统计、筛选、收藏、个人笔记、勾选重练和一键重练待巩固题。
- 学习首页按账号与考试生成每日计划，固定保存推荐专项、错题回炉和单词学习三项任务，并展示推荐原因和真实完成进度。
- 批改和 DeepSeek 深度错题讲解同步返回，页面等待二者完成后一起显示。
- 展示真题来源标签，例如 `2021 年俄语专八真题`。
- 预留学生继续追问入口。

## 2. 启动方式

```text
.venv\Scripts\python.exe scripts\serve_student_app.py --port 8765
```

打开：

```text
http://127.0.0.1:8765/
```

## 4. API

题库状态：

```text
GET /api/status
```

学生账号：

```text
GET /api/users
POST /api/users
```

生成练习：

```text
POST /api/quiz
```

入门诊断同样使用 `/api/quiz`，请求中传入：

```text
mode = diagnostic
count = 30
question_types = grammar_choice / literature_choice / culture_choice / reading_choice
```

提交批改并同步生成讲解：

```text
POST /api/grade
```

读取用户画像：

```text
GET /api/profile?user_id=1
```

读取或生成当天学习计划：

```text
GET /api/study-center
```

同一天返回固定的计划快照。推荐专项调用 `/api/quiz` 时附带 `daily_task_id`，服务器校验任务归属后按当天锁定的知识点组卷。

读取错题本：

```text
GET /api/wrongbook?user_id=1
```

保存错题收藏和个人笔记：

```text
POST /api/wrongbook/item
```

错题重练继续使用 `/api/quiz`，请求中传入：

```text
mode = wrongbook_review
question_ids = 当前学生选择的错题编号
```

服务器会再次验证这些题属于当前登录账号和当前考试；阅读题会扩展为完整文章题组。

内部调试用单独讲解接口：

```text
POST /api/explain
```

内部读取已保存 AI 讲解：

```text
GET /api/thread?id=1
```

继续追问：

```text
POST /api/followup
```

`/api/grade` 会完成批改并同步把本次错题、选项、学生答案、正确答案、来源标签和薄弱点发送到 DeepSeek。前端等待同一个响应完成后，一次性显示批改结果和讲解。追问会把该对话线程历史和学生新问题发送到 DeepSeek，前端仍保留追问前确认。

## 5. 当前验证结果

已验证：

- 首页可访问。
- `/api/status` 返回 300 道已审核题。
- `/api/users` 可返回默认学生账号。
- 学生端可新增和切换本地学生账号。
- 首页已提供约 30 题入门诊断入口。
- 入门诊断包含阅读时会按整篇文章补齐，当前可生成 31 题左右，四类题型约为 8 / 8 / 7 / 8。
- `/api/quiz` 可生成练习，默认不包含阅读题，且不会把正确答案提前返回给前端。
- `/api/quiz` 已参考当前学生的 `question_exposures` 做基础避重排序。
- `/api/quiz` 选择阅读题时按 `passage_id` 抽取整篇文章；抽中一篇文章会连续返回该文章下全部小题，实际题量可向上补齐到完整文章组。
- 学生端同一篇阅读文章只显示一次，后面连续展示该文章的小题。
- 阅读文章在练习页中完整展开，不再放进固定高度的小滚动框。
- `/api/grade` 可批改、写入数据库、同步生成深度错题讲解，并返回完整页面渲染所需数据。
- `/api/profile` 可按学生返回题型掌握度、知识点掌握度、前三个薄弱项和下一步专项训练建议。
- `/api/wrongbook` 可按学生返回错题统计、完整选项、知识点、收藏和个人笔记。
- `/api/study-center` 可按账号、考试和日期生成稳定的三项任务，专项进度只统计对应题型，单词和错题进度读取真实学习记录。
- 错题本可按状态、题型、知识点和关键词筛选，并可生成待巩固或勾选题目的重练卷。
- 前端主导航包含“练习 / 错题本”两个页面，学生账号位于练习页顶部。
- `/api/explain` 保留为内部调试入口。
- DeepSeek 返回内容按结构拆分：逐题讲解显示在对应错题下方；薄弱点排序、复习方案和可追问问题显示在 AI 对话区。
- `/api/thread?id=1` 只返回 assistant 讲解消息，不把系统提示词和底层 JSON 暴露给学生端；学生端不再提供“读取讲解”按钮。

## 6. 后续升级

下一阶段建议：

- 把当前本地服务拆成正式后端 API。
- 将静态页面升级为 React 或 Next.js。
- 加入真实登录、密码或验证码、权限校验。
- 在现有错题本 2.0 基础上增加间隔复习日期和周复盘报告。
- 增加背单词、听力和新闻材料模块。
