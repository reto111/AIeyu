## 需求、引用与质量边界

225本地研究包可准备、重放、逐字校验并定位引句，不发送模型请求。225来源、57派生范围、413跨页引句及620冻结命中表通过工程重放；两个版本分别8次移目录隔离命令无网络/数据库访问。审计钩子不是操作系统沙箱，哈希清单没有数字签名，不能证明发行者身份。

逐字引句校验拒绝来源、问题、提示词、层选择、批准标记、重音和原印声明的篡改。但专门构造的无关主张搭配有效引句仍通过，说明没有验证引文对主张的语义支持。这是确定性工具的模拟响应测试，不是生成模型的回答质量实验。
