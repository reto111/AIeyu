# 可用于论文的三个出处核查案例

以下段落是研究者处理过程的写作底稿，依据本地保存的具体原页或电子原文。它们不是随机抽样，不能据三个案例估计全书错误率；文字校对、转引差异与语义推断分别报告。

## 同一形式不能全局替换：это与эти

《现代俄语体学》PDF356/印刷336引Ткаченко时作кто это люди，同一作者2010年论文仍沿用это。但所查А.С.Ткаченко《Душа живая》（Москва：Советский писатель，1984）《Мелочи жизни》印刷61页作кто эти люди。因此，候选版据文学原作扫描修订这一处字形，同时保留教材对角色和引句的节略处理。原作角色为Деятель，教材作корреспондент，不能因局部字形得到支持就声称整句逐字一致。

同一教材单元另一处это его слова并未随之替换。该处это存在不变助词的合法分析，现有学术语法证据只能支持保守保留这一读法；尚未定位Сизов原作，不能称其文学原句已核验。这个对照说明，跨句字形一致和相邻名词的数不能替代具体用法与出处判断。

证据：[原作61页图](../data/processed/aspect_reference/external_evidence/tkachenko_dusha_p0062.png)、[本次应用记录](../data/processed/aspect_reference/reviews/primary_tkachenko_application_20261023_001.json)。两处教材处理见当前方案的AS-TI-104与保留项AS-TI-103；公开入口为[所查文学扫描目录](https://litmir.club/bd/?b=197580)。2010论文只是同一作者的重复表述，不视为独立文学原作校勘。

## 配合冲突先定位原句：Глаз与Глаза

教材出现Глаза与单数谓语组合时，仅凭句法规则至少可产生改主语、改谓语或改人名主语等不同修复路径。所查Г.Владимов1998年作品集第一卷《Большая руда》PDF134/印刷133实际作单数Глаз，且相邻语境涉及人物眼部受伤。候选据此只修Глаза为Глаз，保留两个单数谓语，撤回凭表面配合直接改谓语复数等猜测。

此例的外证范围是具体主语字形及相邻场景，而非作品集整体校勘，也不证明教材所在单元全部分析正确。研究中应将“语法不协调是检索线索”与“原作提供具体修复依据”分开记录。

证据：[原作对应页图](../data/processed/aspect_reference/external_evidence/vladimov_ss1_1998_p0134.png)、[所查作品集扫描](https://imwerden.de/pdf/vladimov_sobranie_sochineny_tom1_1998__ocr.pdf)，当前方案AS-TI-034。1998为实际核查版本，不据此认定小说首次发表年。

## 字形校对不等于事件分类：Панова的内心爱恋语境

教材PDF260/印刷240选取Панова的一段叙述说明有限次数总和。放大原页可见броня及双н的ветренность；《Спутники》两份电子转录同句为браня себя за ветреность，现代规范词典亦列单н词头。候选将两个修改分别定位为броня→браня与ветренность→ветреность，保留教材转录原值，不使同一原偏移被两条编辑重复覆盖。

出处核查还提供了字形以外的信息：前后文写Юлия对教授及年轻助教的爱恋不为对方所知，并称这些情感是隐秘的幻想。因此，教材节选中的次数表达不能直接用来证明现实肉体关系的反复发生。这个上下文警示不自动推翻作者关于总和意义的形式分析；它要求标注者另分事件词义、人物内心视点、次数所量对象及所提供语境的充分性。候选只改字形并传播警示，没有代写教材译文或将模型解释当作独立结论。

证据：[教材放大原图](../data/processed/aspect_reference/reviews/primary_continuation_visual_20261023_002/aspect_p0260_quote_crop.png)、[所查作品电子原文](https://sheba.spb.ru/rs/panova-sputniki.htm)、[另一电子转录的具体段落](https://knizhnik.org/vera-panova/sputniki-serezha-sentimentalnyj-roman/12)、[规范词条裁图](../data/processed/aspect_reference/external_evidence/gramota_orthographic_ветреность_p0298.png)。未核教材书目所列1980纸本；两网站文字相同也不证明它们拥有独立的转录来源。

三个案例分别体现局部用法辨析、据原作选择修复路径、及引文语境对事件分类的制约。统计口径与当前128处修改的证据分类见[论文方法底稿003](aspect_reference_thesis_data_note_20261023_003.md)；这些段落没有引入自然语料频率、独立专家评分或生成实验结果。
