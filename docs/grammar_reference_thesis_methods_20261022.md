# 语法RAG研究方法与结果底稿（2026-10-22）

本文档可用于起草论文的数据、方法、实验与局限性部分。其记录的是已经完成的开发性实验，尚未经独立俄语专家或导师盲评。以下“覆盖”均指预设要点，不等于规范语法正确率或全书转录正确率。

## 数据构建与版本

研究材料为本地扫描版《当代俄语语法》（数据库来源标题记张会森，2010；正式参考文献的出版信息仍须以版权页核对）。原PDF共有641页，其中正文审核覆盖613页。扫描资料经识别、逐页对照及跨页片段接续，形成369个完整章节单位，采用SQLite保存原页审核记录、来源指纹、分节正文、批次及历史修订。OCR输出不直接视为已审核文本。

本研究保留两个不可混用的语料版本。原转录研究版v1有232节可检索，137节因原书疑点或转录、表格问题隔离。用户随后授权对疑点自主复核；173条问题记录均有处理结果，并保留模型判断、外部证据及用户裁定的区别。编校研究版v2以独立修订层保存207处编辑，368节可检索，1份整附表继续隔离，另有2个例子仅留于原转录归档。173条是问题记录数，可能重复或一条含多问题，不能作为独立错误数计算错误率。

原页文字与编校正文分别保存。编校内容标记为`editorial_research`，不得以“原书逐字原文”名义引用；可检索也不表示经过专家正确性认证。程序可以将每个原转录节绑定到页记录，并按编辑旧值与位置重放生成编校正文。本轮重新验证全部368个可检索节、v2的21个文件指纹及v1的38个文件指纹，原转录数据库指纹未改变。指纹及重放证明版本与来源一致性，不证明语言学内容正确。

版本依据：[v2说明](grammar_reference_editorial_release_20261018.md)、[本轮实验报告](grammar_reference_generation_pilot_20261022.md)。

## 检索和生成设计

检索采用本地、有限的中俄关键词及书内主题匹配，依据标题命中和受限词频进行排序。检索仅从ready章节返回资料，不使用向量数据库或外部检索服务。每题最多选3个完整章节，正文预算16000字符；整节超预算时省略并记录，不偷偷截短或人工补入金标准章节。搜索可以忽略俄语重音，但引文保留源文重音及ё，只有Markdown星号和反引号在引用匹配表示中被去掉。

试验在调用前冻结10道问题、26项评分要点、目标来源、系统提示词及配置。目标来源只用于评分；RAG上下文由自然问题检索产生。两组均使用现有DeepSeek，配置模型`deepseek-v4-flash`，温度0、thinking disabled、输出上限1400 token、JSON格式。实际提供方模型标识及usage保存在原始响应中。两组使用相同系统提示词，无RAG组允许依据已有语法知识回答，不被强制拒绝全部无资料问题；两组均不得编造该书引文、页码和统计。

每题各调用有RAG和无RAG一次，共20次；按题交替调用顺序，各有5题先调用RAG、5题先调用对照。20次均成功结束，没有自动重试或截断响应。该设计不是随机独立重复试验；温度0也不能被表述为提供方完全确定性保证。服务时间仅为本轮实测，不代表普遍性能。

所有请求开始前先保存消耗标记，失败或中断也计入上限。已消耗20次后重跑不会产生额外请求，相关零网络调用测试通过。生成试验仅外发用户明确授权的书中片段、问题及来源元数据，没有发送学生学习记录，没有写学生数据库或部署到学生端。

可复查的冻结材料为[protocol.json](../data/processed/grammar_reference/rag/generation_pilot_20261022_001/protocol.json)，原始响应在同目录`responses/`中。

## 指标定义

1. **检索目标覆盖**：实际证据包是否包含预设目标节。双节题要求两个目标均被包含。该指标只度量指定来源的覆盖，不代表所返回全部内容相关或足以作答。
2. **要点覆盖**：同一助手据预先冻结的逐项要求给0或1分，矛盾陈述不满足该完整要点。拒绝冒称本书表述与一般语法错误分开记录；扩展主张另作阅读审核。不能把该分数直接称为答案正确率。
3. **引用机械合规**：回答结构有效，每条主张有来源ID和至少6个非空白字符的连续逐字引句，来源正文、页范围与编校标签仍能重放绑定。引用匹配不去重音，不把е和ё互换。
4. **逐条引文支持**：同一助手检查“该条实际给出的引句”能否覆盖主张的全部细节，分别记为现有引句支持、需补上下文、无引用。该判断不是独立盲评；需补上下文不等于事实错误，完整章节或其他主张可能提供支持。
5. **范围拒绝诊断**：对要求外部语料库计数、个人学习指标、音频下载等非本入口能力的问题，检查是否还会准备生成提示词。有限规则的allow不是充分性证明；未准备提示词也不代表已证明原书绝无相关内容。

评分与错误依据见[audit_001.json](../data/processed/grammar_reference/rag/generation_pilot_20261022_001/audit_001.json)。

## 观察结果及分层披露

10题总分为有RAG26/26、无RAG15/26。为避免把“本书特定信息”天然需要资料的优势混同于一般语法能力，另进行事后分层，原始分数未改：

|题目层次|题数|有RAG要点|无RAG要点|全部要点覆盖题数（RAG/对照）|
|---|---:|---:|---:|---:|
|一般语法|8|21/21|12/21|8/8、3/8|
|本书特定用法变化表述|1|3/3|1/3|1/1、0/1|
|无依据的语料库统计请求|1|2/2|2/2|1/1、1/1|

分层是为解释任务不对称而进行的事后描述，不是预注册的独立终点。P02无RAG组合理拒绝声称了解本书，同时提供一般知识，因此未覆盖书内叙述的分数差不能解释成语法错误。P10两组均拒绝编造次数和日期。本轮可以观察到无RAG在数词第二格、集合数词重音等题中的具体错误被RAG答案避免，但不能凭10题推断总体因果效应。

有RAG的9份实质回答中只有6份通过全部机械引用条件；一般语法8题中通过5份。另1份材料不足响应通过结构校验。39处引用中37处逐字存在，36处还满足最短长度。失败含5字短引句、сказала重音改变、Markdown格式差异及无引文的一般知识补充。失败原样保存，没有追加调用修复或修改阈值。

对27条实质主张继续逐项阅读：14条现有引句能覆盖所述细节，12条需补上下文，1条无引用。例如某条给出全部变格形式，却只引用“сорок重音移到词尾”；该引句真实存在，但不足以覆盖全部形式。这是引用充分性问题，不能用“引句存在率”替代。P04另有原书第四格重音表述简化，需结合表格、动物性和同第二格条件理解；本次据源覆盖不替代规范评议。

全部provider usage为69095 token，其中输入64608、输出4487。RAG组输入61492 token、输出2871 token；对照输入3116 token、输出1616 token。RAG/对照单请求中位时间约1.94/1.58秒，全部请求耗时之和19.50/15.90秒。输入包含提供方报告的缓存token，未据未核实单价计算费用；这些数字也不代表Codex周额度。检索、材料准备及人工式阅读整理的时间不在请求延迟内。

## 检索扩容与后续候选

复用旧40题对编校v2进行版本回归时，单节24题top3为17/24，低于原232节v1的21/24，说明扩大可用语料会产生竞争；不能仅以语料更多推断召回提高。双节8题均覆盖全部目标，4道普通无关题空返回，4道原隔离现可用题命中3道。该组旧题是回归集，不是新盲题。

独立候选通过有限中文描述扩展到书内主题，默认和封存版保持原样。40题中36道有目标题全部目标覆盖从28/36升至35/36；20道在执行前冻结的新表述中，17道有目标题从9/17升至17/17，普通负例仍为空。新题由同一助手针对已知缺口设计，不具独立性，也不能用来声称普遍17/17正确。

另增可选保护入口，重放整份请求、提示词与来源，避免只校验正文却接受已被替换的提示词。24条先冻结的范围正反例符合预期，8道旧主题重叠范围外问题拦截7道；“程序内存需求”仍漏判。60题检索回放中没有已有目标命中被范围规则误拦，候选和默认检索命中数保持不变。这只是有限规则的诊断结果，不能宣称解决通用语义范围识别。新提示词未调用生成，不能回写为旧实验的新结果。

## 可主张的结论与不能主张的结论

现有证据支持：建立了保留原页和编校差异的可追溯语法数据库；实现了受来源状态限制的检索；在一次小规模配对生成中记录到若干具体语法错误的避免，也记录了引文合规与充分性失败；所有旧结果和失败可回查。

现有证据不支持：全书零错、所有编校均经独立资料核实、RAG总体正确率100%、具有统计显著提升、已通过俄语专家验收、候选检索已完成生成评价，或学生端已经上线。

正式论文还需独立俄语专业评阅者按固定手册评分，明确题目抽样框、错误严重程度及争议处理；扩大样本时另行确定生成数量范围。应同时报告事实内容、资料归属、引用逐字性和引用充分性，保留合理拒答，避免只报告有利的总分。当前20次外部生成授权已全部消耗，本轮后续工作均为本地处理。

补充工程交付：[独立本地包与引句页定位](grammar_reference_guarded_release_20261022.md)。页定位重放覆盖368节、565855个去排版符号字符，39处实验引句37处可定位；重复表行保留多页候选，编校派生文字单列。映射依据是页转录与编辑日志，不是PDF字形坐标或语义正确性证明。
