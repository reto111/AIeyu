# 《现代俄语体学》知识库：论文方法与工程结果底稿

本底稿可作为论文中“理论资源整理与可追溯知识库构建”的材料。它不包含已完成的自然语料采集、独立专家评价或模型生成效果实验。另有42项统计记录登记在[事实清单](../data/processed/aspect_reference/reviews/thesis_fact_sheet_20261024_001.json)，逐项绑定8个固定版本报告的哈希与JSON字段；[清单验收](../data/processed/aspect_reference/reviews/thesis_fact_sheet_verification_20261024_001.json)已通过。正式论文仍需作者按实际研究问题编辑和核对引文。

## 研究材料及用途

研究选用张家骅《现代俄语体学（修订本）》（北京：高等教育出版社，2004年第2版；ISBN 7-04-014221-X）作为俄语体范畴的理论依据与教学例证来源。书目信息由PDF2–3定位，原件共481页。知识库累计审核材料涉及471个来源页，其中470整页、1局部页；这不表示481页全部完成逐字审定。理论材料按章节组织为100单元，其他60单元作为练习、答案、书目等另存并排除于理论检索范围。

教材例句由作者围绕语法解释选择、节略、翻译和编排，材料中存在词偶、比较组、对话、多句段落、星号例、括号改写和跨章重引。因此，本研究将其界定为理论及教学例证资源，不将教材例证频次解释为当代俄语实际使用频次，也不把教材俄汉对应解释为自然平行语料。

## 来源分层及编校

原PDF、页图、归档转录、编校候选与研究标注分别保存。归档转录保留当时的线性化结果及历史疑点；候选通过具有原值、新值、稳定单元键、文本偏移和理由的编辑重放生成。来源偏移始终指向原转录正文，不能拿候选文本的字符位置替换原始坐标。文字修正、来源可用范围、语义判断和批准进入训练池是不同操作。

当前候选002包含40个原ready单元、53个模型编校候选、7个隔离单元。默认理论入口只返回40个原ready；主动开启候选范围时最多返回93单元，7隔离单元在两种模式均不返回。原ready是本项目转录工作流的状态，不等同于独立专家审定。候选的128处编辑中，115处位于可用候选范围，13处随隔离材料归档，不据“存在编辑”解除隔离。原转录库保持原状态，未以候选覆盖原文。

查证证据包括原书页图、规范词典、文学原作扫描、电子转录及同一作者的后续论文，不将这些来源视为等强证据。同一作者重复使用某种表述不能替代文学原作核查，两网站文字一致也不能证明转录来源独立。[三个案例](aspect_reference_thesis_evidence_cases_20261023.md)分别记录据原作选择局部修复、合法形式保留及原作语境对事件分类的约束。7项疑点仍包括5项文学出处、1项理论出处和1项墨迹遮挡，不能写作“全部疑点解决”。

## 标注与独立评价准备

另对8道主题重叠范围外题进行了[选定引句充分性分析](aspect_reference_evidence_sufficiency_20261024.md)：3空返回、5非空返回均重放旧状态和来源顺序。5处真实语法引句不足以提供所问学费、账号结果、任课安排、个人成绩或本周菜单。本地刻意不受支持的5条合成主张可通过引用存在性检查，但检查明确不评语义；这不是5次真实模型生成失败，也不能推算模型幻觉率。全部返回正文尚未独立逐篇作语义评定。

现有22目标多轴试标含39段依据与110轴值，由同一助手完成。话语地位、行为发生承诺、词汇目标达成、参照时结果状态及后果相关性分别记录，不因完成体形式直接推断目标达成或物理结果状态保持。`unknown`、`not_applicable`与`not_committed`含义不同，空白只表示尚未填写。

原22目标复核包有两份CSV、264个空分类格，实际独立标注0。新增[57译对复核包](../data/processed/aspect_reference/research_exports/aspect_translation_review_20261024_001/README.md)另有342个空分类格，评价整例范围、翻译充分性和语境充分性；评价对象统一为候选文本，原转录可见。两项任务不混算为同一种语义评价。译对复核包已核57来源/114语言片段及空表输出，但没有人类评阅结果。

评阅者须分别独立填写，保留原始表，另存裁决记录。工具逐字段使用双方共同填写项目计算原始一致率和名义Cohen κ，报告各自缺标及明确未决类别。空表共同填写数为0，一致率和κ为空；单一常数边际的κ未定义。不同评阅ID不证明实际人员独立，高一致率也不等于正确率。现阶段不能报告专家一致率、翻译准确率或模型对专家的优越性。

## 可重现性与论文结论边界

[研究ZIP002](aspect_reference_research_delivery_20261024_002.md)包括12包、15份证据报告、137文件，采用固定ZIP元数据，可重新构建为相同字节。项目外临时环境使用审计钩子禁止联网及读取项目，16个只读入口场景通过；414张实际来源页图文件指纹、原PDF及原库指纹一致。此处414为文件绑定核对范围，不是新做414页视觉审核。新译对复核包晚于ZIP002封存，独立交付，未静默写回旧ZIP。

本文目前能够支持的结论是：完成了具有来源分层、版本固定、偏移追踪、范围隔离及可运行查询的教材研究资源；识别并记录了教材例证计量与自然语料计量的差异；得到特定开发题上的检索和单门槛消融结果。尚不能支持全书逐字正确率、自然语料分布、专家金标、正式检索泛化能力或生成模型教学收益的结论。后续研究应按实际论文问题另行确定自然语料来源、抽样框、独立评阅人员和评价协议。
