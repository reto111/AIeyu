# 体学知识库范围规则候选：失败与使用边界

本地独立脚本scripts/aspect_evidence_scope_candidate.py是研究实验，没有替换默认RAG、调用生成API或接入学生界面。其目的是区分教材语言理论与教材没有的学校、账号、价格、当前事实及自然语料计数；它不能判断任意引句是否蕴涵答案。

在实现前冻结[40道开发性评估题](../data/processed/aspect_reference/rag/evidence_scope_cases_20261023_001.json)，含16事实、16语言例子、8混合请求；均同一助手依据已知失败设计，不是独立留出。规则遮蔽成对引号内的例子，再以少量中俄文任务/事实/领域词判断。

|题组|路由匹配|实际行为|
|---|---|---|
|首组16事实|16/16|词项原15、passage原11题有材料；候选均阻断|
|首组16语言例子|15/16|1题未分类但仍按原检索；16题来源均保持|
|首组8混合|8/8|保留理论来源，提示包明示外部事实不足|
|旧8重叠范围外|6/8阻断|考场和下学期授课人漏判，仍错误取得材料|
|追加8口语事实压力|0/8|词项7、passage5题仍有资料；事实请求未被识别|
|追加4语言压力|0/4|全部误判为混合，来源未删但误加部分证据限制|
|追加4混合压力|0/4|全未识别混合性，词项4、passage3题仍有资料|

实际结果见[40题报告](../data/processed/aspect_reference/rag/evidence_scope_evaluation_20261023_001.json)、[16题压力用例](../data/processed/aspect_reference/rag/evidence_scope_stress_cases_20261023_001.json)及[压力报告](../data/processed/aspect_reference/rag/evidence_scope_stress_evaluation_20261023_001.json)。压力题在首版实现后、首次执行前保存，刻意覆盖词表缺词及引号真实请求，不是独立自然分布。报告后没有据题修改规则。

“明天考试在哪间教室”缺少词表中的事实线索，即使含教室也漏判；“请直接回答引号中的成绩问题”被遮蔽真正任务；非引号的语言例子提及现在价格时又误判为实际事实请求。这表明句子任务、引用辖域和事实指称不能由这套词表可靠分离。

该候选不建议用于实际证据门控。保留它仅用于论文中的对照与错误分类，不把首组39/40当总体准确率，不汇成一个掩盖分布变化的高分。路由是否匹配、资料是否空返回、来源是否支持主张和生成答案是否正确是不同指标。语言分析被允许检索，也不保证书中有答案；混合请求加限制，更不证明模型一定遵守。

本实验保持候选007、原排序与原冻结50题报告不变。4项新行为测试只验证被识别后的执行约束：事实分支不调用教材检索、混合限制进入实际prompt_package、引用样例及俄语计数例子的预定路由；不证明语义泛化。连同既有项目相关测试共30项通过。
