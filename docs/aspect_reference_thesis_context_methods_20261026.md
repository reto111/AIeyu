# 论文方法补充：教材例证的语境、对应与改写关系

本节依据[主交付004](aspect_reference_inline_extension_20261026_042.md)及其内含语境补充001编写，可作为论文“资料处理”部分的底稿。[16项数据依据](../data/processed/aspect_reference/reviews/thesis_context_methods_facts_20261026_001.json)由9份固定来源导出。它不改旧42项统计快照，也不增加自然语料实测结果。

## 可用于正文的处理方法说明

本研究将教材例证视为带有解释语境的研究资料，分别保存归档转录、编校候选及其编辑证据。资料按稳定来源ID关联原页与单元指纹；例组、词项释义、句级对应、作者改写和理论分析不混为同一统计单位。当前版本保留1453个编号组和725个行内组，默认返回511组原ready来源，显式启用候选后可返回2061组，117组来源隔离。这里的ready表示来源层状态，不意味着例证在语言学上都可接受，更不表示已可直接投入训练。

对于带否定或限制措辞的段落，先确定作者是在限定理论归因、否定释义等值、排除某种读法，还是讨论特定语境中的用法。定向筛查覆盖16段、19处字面线索，并核22个原页；与段落有区间交叠的65个既有例证不自动继承段落类别。原页星号另按字符位置保留：当前40个片段含50个星号，90个自身无星号片段的上下文也含星号；后者不因此统一归入负例。

俄汉对应不以相邻排布为唯一依据。第241页两个俄语问句的中文译文出现在中间分析之后，作者以“第一句/第二句”明确指向。本研究分别保存两端的绝对范围与指示语，将这2条作为非连续对应补充层保留，不拼成原书中不存在的连续文本，也不直接加到冻结的435处行内对应上。

作者对译文的改写须区别于新的语料出现。第398–399页同一叙事例组的5个小句，原译与变体之间有两处去“了”、两处加“了”、一处保留；这些记录属于同一来源组内部的比较。第200–201页则有1条作者在原语境允许的改写，以及2条会使意义转向责备行为结果不当的改写警示。后两条既不作为原义不变的译对，也不被概括为这些句子普遍不合语法。

## 实际验证与适用范围

主004共431文件、56项隔离CLI通过，另有字节一致重建；语境补充001重放11单元的79处原转录与55处候选范围。这些工程检查验证定位、版本、编辑和访问范围，并不证明翻译正确率或语言学判断普适性。AS-TI-118例号和AS-TI-049汉译等既有候选修订始终与原转录分列，不在新关联中悄然覆盖。

上述案例通过既有队列、明确翻译线索和标记位置定向发现，不是随机抽样，不能用案例数量估计教材错误率。全部范围备注由同一助手完成，独立专家评价0；空表不填作专家结果，也没有本书新增生成对照。正式自然语料分析仍需另定来源、抽样、去重、逐谓词及话语语境标注，并实施独立评阅与分歧裁决。
