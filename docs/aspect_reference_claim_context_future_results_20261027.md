# 将来意愿与完成体过去结果后果补核

完整复读第七章§2、第八章§1及§2.1，对11条主张补28个语境范围，本轮重点核8页原图。11条短引句需补对象、条件或对比。原3处候选编辑保留。累计222条有针对性记录、128条待补录，独立专家0。

未来结果作为语用预设时，未完成体分析式可询问实施意愿、突出时间方式等或为相关请求建立前提；这不保证未来事件实际发生。近义替换也不意味着意愿与必要性完全相同。反诘与反语可表达无意或无须实施，不能把所有将来形式视作肯定计划。

完成体过去的一般过去用法着眼整体事件，与后来的结果存在分开；完成体本身不保证结果延续至今。次第、时间因果、过程终止和事件开启后过程等叙事结构分别保存，开始事件条目补整段例9至11，不只保留标题。

一般结果存在不仅检验预料行动，也可解释当前现象、情感理由和评价结果。应该/可能发生与已经发生属于不同预设。空间姿态结果已经消失时，后果仍可能相关：离开付款处不取消迟到后果，离开冰窟窿不取消感冒理由。本书明确反对因此机械改成未完成体结果取消。
