# PDF 题目识别方案对比（2024 专四扫描卷）

## 目的

比较以下两条流程的速度与准确率：

1. OCR + 规则复核：去水印、300 DPI 渲染、Tesseract OCR、题号与选项规则切分。
2. OCR + 规则复核 + 多模态复核：在流程 1 后，将原始页面图、OCR 文本和结构化题目一起交给视觉模型逐题核对。

## 样本与标准

- 文件：2024 年俄语专四扫描版真题。
- 准确率样本：第 18–56 题，共 39 题、4 页。
- 同页计时样本：第 37–56 题，共 20 题、2 页。
- 金标准：先读取人工修正数据库，再逐项对照原始页面裁定冲突。数据库不能直接作为唯一金标准，因为抽样发现其中仍有旧 OCR 遗留。
- 统一忽略 `е/ё` 的排印差异；保留题干空位、词语、标点和 A–D 结构差异。

## 同页实测结果

| 指标 | OCR + 规则 | 再加一次多模态复核 |
| --- | ---: | ---: |
| 两页处理时间 | 3.559 秒 | 78.547 秒 |
| 字符准确率 | 85.02% | 99.90% |
| 题干/选项字段完全一致率 | 72.00% | 99.00% |
| A–D 四选项完整率 | 95.00% | 100.00% |
| 整题完全一致率 | 0% | 95.00% |

说明：传统流程的整题完全一致率为 0%，主要因为旧切分结果普遍丢失题干中的空位标记，并不表示每道题完全不可读。多模态第一次复核仍多写了一个逗号；第二次原图复核后，抽样达到 100%，但会继续增加耗时。

在完整 39 题准确率样本中，传统流程字符准确率为 84.71%、字段完全一致率为 72.82%；第一次多模态复核分别为 95.78% 和 89.23%。这说明视觉复核能显著提升质量，但单次模型输出仍可能发生视觉误读或擅自改写。

## 结论与正式流程

- 速度：OCR + 规则明显更快；本次同页测试约快 22 倍。
- 准确率：多模态复核明显更高，尤其擅长恢复空位、跨页选项和被页眉页脚污染的内容。
- 可复制文字版 PDF：优先直接提取文本，不走 OCR；规则校验失败时才调用多模态。
- 扫描版 PDF：先批量 OCR，再只把高风险题送多模态复核。高风险包括缺少 A–D、跨页、低置信度、异常字符、题干无空位、答案无法匹配、页眉页脚混入。
- 入库前质量门禁：多模态只能生成修订候选；必须再次运行结构规则和俄语语言规则。低置信度或两次结果冲突的题进入人工审核表。

该混合流程兼顾速度、成本和可靠性，适合作为后续专四、专八真题接入的默认方案。
