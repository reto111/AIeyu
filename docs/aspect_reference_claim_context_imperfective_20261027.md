# 四类未完成体意义的主张补核

本批完整阅读第一章§4.9—4.12，核PDF64—74/印刷44—54相关原图，补14条主张与27个语境范围。4条短引句已涵盖本条陈述，9条需前后定义、条件或例后分析，1条含助手的谨慎范围推导。6条原ready、8条候选不升级。

“无限次数”是次数不受界限限制的语义标签，不能转写成发生数学无穷多次的实测断言。性质说明可能表达能力而非已发生的重复；分配重复又只是重复的一部分，单数名词在каждый/любой条件下也可表分配。形式上的单复数不是孤立的充分判据。

概括事实可以由语境的一次/多次状语确定句子事件数量，同时动词体形式本身不承担该次数意义；二者不矛盾。其交际焦点与行为客观持续性、结果因素分开，不能因句中客观有过程就一律判为具体过程意义。

未完成体结果存在单元说“主要”涉及少数感受认知词，并非“只有”这些词；后文明确列出есть、умываться等否定用法。卡片“不能扩展到所有未完成体”是项目谨慎原则，不当作教材已给出封闭词表或证明所有例外。原卡措辞不回写，推导层级单列。
