# Russian AI Tutor Product Requirements

> 本文档是俄语 AI 私教项目的产品需求文档。
> 若本文档与 `docs/PROJECT_CONTEXT.md` 冲突，应先确认最新标准，再同步更新两处文档。

## 1. 产品概述

本项目是一款面向俄语专业八级考试的 AI 私教型学习与测评系统。

第一阶段聚焦俄语专八，围绕真题题库、随机组卷、自动批改、错因分析、中文讲解、追问答疑和巩固练习形成学习闭环。后续需要扩展到俄语专四、TORFL / ТРКИ、A1-C2 等其他考试或等级体系。

产品定位：

- 不是单纯的考试刷题系统。
- 是带有测评能力的俄语 AI 私教。
- 重点帮助学生知道“错在哪里、为什么错、怎么补、下一步练什么”。

## 2. 产品目标

### 2.1 第一阶段目标

V0.1 的目标是跑通专八选择题和阅读题的学习闭环：

```text
录入题库 -> 组卷 -> 答题 -> 批改 -> 错因分析 -> 中文讲解 -> 巩固练习
```

### 2.2 长期目标

- 支持多考试体系和多等级选择。
- 支持班级试用和教师管理。
- 支持 AI 对话式讲题。
- 支持基于 RAG 的资料引用和知识讲解。
- 支持 AI 生成题目的人工审核流程。
- 支持商业化部署和内容管理。

## 3. 目标用户

### 3.1 学生

学生主要需求：

- 快速练习俄语专八题目。
- 知道自己哪些知识点薄弱。
- 获得中文讲解。
- 对不懂的题目继续追问。
- 获得针对性巩固练习。

### 3.2 教师

教师主要需求：

- 上传和整理真题。
- 审核题目和解析。
- 给学生布置练习。
- 查看学生和班级薄弱点。
- 后续导出学习报告。

### 3.3 管理者

管理者主要需求：

- 管理考试体系、题型、知识点。
- 管理题库来源和审核状态。
- 管理 AI 生成内容。
- 后续管理商业化权限和内容版权。

## 4. 第一版范围

### 4.1 包含功能

V0.1 包含：

- 俄语专八考试体系。
- 语法选择题。
- 文学选择题。
- 国情选择题。
- 阅读理解选择题。
- 题库录入与编辑。
- 题目知识点标注。
- 随机组卷。
- 用户答题。
- 自动批改。
- 错题统计。
- 中文错因分析。
- 基础题目解析展示。
- 基础巩固练习生成。

### 4.2 暂不包含功能

V0.1 暂不包含：

- 听力题。
- 写作题。
- 口语题。
- 复杂班级管理。
- 支付和订阅。
- 多机构管理。
- 大规模公开部署。
- 完整移动端 App。

## 5. 核心用户流程

### 5.1 学生练习流程

```text
进入系统
  -> 选择考试：俄语专八
  -> 选择题型：语法 / 文学 / 国情 / 阅读
  -> 选择题量
  -> 开始答题
  -> 提交答案
  -> 查看批改结果
  -> 查看错因分析
  -> 查看题目讲解
  -> 继续追问 AI
  -> 完成巩固练习
```

### 5.2 教师整理题库流程

```text
上传 PDF 真题
  -> 系统解析文本和题目
  -> 教师检查题干、选项、答案
  -> 标注题型和知识点
  -> 填写或审核解析
  -> 设置难度和来源
  -> 发布到正式题库
```

### 5.3 AI 私教答疑流程

```text
学生打开某道错题
  -> 查看中文解析
  -> 在对话窗口追问
  -> 系统检索题目、答案、知识点和 RAG 资料
  -> AI 生成中文解释
  -> 学生继续追问或请求类似题
```

## 6. 功能需求

### 6.1 考试体系管理

系统应支持可扩展考试体系。

第一版默认：

- 考试体系：俄语专八
- 等级：专八

后续可扩展：

- 俄语专四
- TORFL / ТРКИ
- A1-C2
- 自定义考试

### 6.2 知识点管理

系统应支持知识点树。

第一版知识点大类：

- 语法
- 文学
- 国情
- 阅读

每道题必须至少绑定一个知识点。若暂时无法准确标注，可进入待标注状态，但不能作为正式分析依据。

### 6.3 题库管理

题库应支持：

- 新增题目。
- 编辑题目。
- 设置题型。
- 设置选项。
- 设置正确答案。
- 设置解析。
- 设置知识点。
- 设置难度。
- 设置来源。
- 设置年份和原题号。
- 设置审核状态。

题目状态建议：

- `draft`: 草稿。
- `needs_review`: 待审核。
- `approved`: 已审核，可正式使用。
- `rejected`: 已拒绝。
- `archived`: 已归档。

### 6.4 PDF 导入

系统应支持上传 PDF 真题。

PDF 导入后，应进入人工校对流程。不得默认把自动解析结果直接发布为正式题库。

需要保留：

- 原始文件名。
- 来源说明。
- 页码。
- 题号。
- 解析状态。
- 校对状态。

### 6.5 组卷

系统应支持：

- 按题型随机组卷。
- 按题量生成测试。
- 后续支持按知识点组卷。
- 后续支持按薄弱点自适应组卷。

V0.1 最小要求：

- 用户选择题型。
- 用户选择题量。
- 系统从已审核题库中随机抽题。

### 6.6 答题

系统应支持：

- 单选题作答。
- 阅读文章加小题作答。
- 保存用户选择。
- 提交后锁定本次答案。
- 显示完成进度。

### 6.7 自动批改

系统应支持：

- 判断每道题正确或错误。
- 计算总分和正确率。
- 按题型统计正确率。
- 按知识点统计正确率。
- 记录用户本次答题结果。

### 6.8 错因分析

系统应输出：

- 本次测试总览。
- 错题列表。
- 错误集中的知识点。
- 可能错误原因。
- 优先复习建议。
- 下一步巩固练习建议。

错因分析应以结构化数据为基础，AI 负责表达和解释。

### 6.9 题目讲解

题目讲解应包括：

- 正确答案。
- 正确选项原因。
- 错误选项排除理由。
- 对应知识点。
- 中文解释。
- 必要俄语例句。

阅读题讲解应包括：

- 原文定位。
- 正确答案依据。
- 干扰项分析。
- 生词或关键表达解释。

### 6.10 AI 对话窗口

系统应提供针对题目或测试结果的 AI 对话窗口。

对话上下文至少应包含：

- 当前题目。
- 用户答案。
- 正确答案。
- 题目解析。
- 知识点标签。
- 用户本次测试表现。
- RAG 检索资料，若已接入。

AI 回答默认使用中文。

### 6.11 巩固练习

系统应根据错题和薄弱知识点生成巩固练习。

第一版可以先生成临时练习，不直接进入正式题库。

后续商业化时，AI 生成题目需要进入人工审核流程：

```text
AI 生成 -> 待审核 -> 人工修改/确认 -> 正式入库
```

### 6.12 学习画像

系统应逐步记录：

- 用户做过哪些测试。
- 每次测试正确率。
- 每个知识点正确率。
- 重复错误知识点。
- 错题历史。
- 巩固练习完成情况。

V0.1 可先实现基础记录，后续再做可视化看板。

## 7. 数据需求

### 7.1 题目数据

每道题至少包含：

- `id`
- `exam_system`
- `level`
- `question_type`
- `stem`
- `options`
- `correct_answer`
- `explanation`
- `knowledge_points`
- `difficulty`
- `source`
- `source_year`
- `source_question_number`
- `review_status`

### 7.2 阅读题数据

阅读题应包含：

- 阅读文章正文。
- 文章来源。
- 小题列表。
- 每道小题选项。
- 每道小题答案。
- 原文定位。
- 解析。

### 7.3 用户学习数据

用户学习数据应包含：

- 用户 ID。
- 测试记录。
- 答题记录。
- 错题记录。
- 知识点掌握度。
- AI 对话记录，若用户允许保存。

## 8. RAG 知识库需求

RAG 不替代题库。

RAG 知识库用于：

- 语法讲解。
- 文学背景。
- 国情知识。
- 阅读材料背景。
- 考试大纲。
- 教师讲义。
- 真题解析。

RAGFlow 是当前候选方案。

接入 RAGFlow 前需要验证：

- 俄语 PDF 解析质量。
- 扫描件 OCR 效果。
- 中文和俄文混合检索效果。
- 文档切片是否适合语法和文学国情资料。
- 引用定位是否准确。
- API 是否方便接入主系统。

## 9. 非功能需求

### 9.1 可扩展性

系统从第一版开始应支持：

- 多考试体系。
- 多等级。
- 多题型。
- 多知识点。
- 多用户。
- 后续班级管理。

### 9.2 准确性

系统不得把 AI 生成内容默认当成标准答案。

正式题库必须依赖：

- 标准答案。
- 人工审核。
- 可追踪来源。

### 9.3 可维护性

项目应保持：

- 清晰目录结构。
- 文档化需求。
- Git 版本控制。
- 小步提交。
- 可回退。

### 9.4 隐私与版权

需要注意：

- 学生学习数据属于隐私数据。
- 真题 PDF 可能涉及版权。
- 商业化前必须确认内容授权范围。
- `.env`、原始 PDF 和私人数据不应提交到公开仓库。

## 10. V0.1 验收标准

V0.1 达成标准：

- 可以录入或导入一批俄语专八题目。
- 每道正式题都有题型、答案和知识点标签。
- 用户可以选择题型和题量生成测试。
- 用户可以完成答题并提交。
- 系统可以自动批改选择题。
- 系统可以显示总分、正确率和错题。
- 系统可以按知识点统计错误。
- AI 可以用中文生成错因分析和复习建议。
- 系统可以生成一组针对薄弱知识点的巩固练习。
- 项目文档和代码进入 Git 版本控制。
