## 冻结与输入

[协议001](../data/processed/tonglun_reference/rag/question_protocol_20261025_001.json)在首次运行前冻结代码指纹、题目、手给关键词、目标代码与目标正文指纹。150个问题和150个目标均沿用同一助手既有开发材料；不是新盲测题集或独立专家评价。两组都检索原175个ready单元，top5预算相同，未加入39条编校补证预览或附录候选。

关键词组使用原开发题手给关键词；问句组只接收自然问句。这一比较测量减少手给关键词后指定目标的命中变化，不能当作同等信息条件下的语义模型优劣。目录302个标题只用于识别查询主题；隔离标题可以帮助识别问题，但隔离正文不进入结果。协议不单独打包整库，其语料身份接续13:06正文封存及本轮原库逐表一致性检查。

实现仅从目录标题及标题的结构性后缀提取中文词面主题，保留长词优先和连接号形式变体；俄文按完整词形匹配，不作词形还原。按标题、正文封顶计数及文档频率排序，无网络或生成调用。它不理解问题的真实意图，也不判定来源能否充分回答问题。
