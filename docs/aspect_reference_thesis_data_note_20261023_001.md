# 论文数据与方法口径底稿：92节研究版本

本底稿对应[候选007、索引005及多轴附层](aspect_reference_research_progress_20261023_001.md)，更新于2026-10-23。用于论文理论与方法起草，不代替导师或独立专家验收。

本研究以张家骅《现代俄语体学（修订本）》（2004年第2版）作为俄语体范畴的理论和教学引例来源，建立可回溯至原PDF页及印刷页的知识库。教学专著的引例经过作者选取、节略和编排，不能据其数量估计俄语自然使用频率。本库为后续自然语料研究提供概念、对照和可定位引文，不能替代自然语料抽样。

原印层保留471来源页记录、135审核批次、40历史页修订、100理论及60非理论单元。原印40理论单元ready、60 unresolved保持不变；独立候选层允许40原ready＋52模型候选，8理论及60非理论单元仍排除。116条提案含125处修改，112处在允许节、13处在隔离节。原125疑点分为109形成方案、8保守保留、6待出处、1理论语境、1墨迹；另7项追加记录不混入125的分母。一条记录可能包含多个问题。

修改保留旧值、新值、原单位偏移、稳定来源键及原页证据，同时按原偏移重建候选。外部来源28项共61证据文件，区分原刊扫描、电子转录、同作者后续论述及模型中文判断。Рыбин电子原作支持漏л恢复与飞船语境改译，但不因此声称核验了纸本版次或全篇引文。

22个教材目标用于发展标注规范，含18俄语和4汉语。多轴002在旧试标之外保存相互约束的词元/体/时态候选和作者选择，分离目标形态时、构式时、事件时间、话语地位、发生承诺、词汇目标达成、参照时结果状态及后果相关性。39段解释引句绑定原页，了₁/了₂、助动词和量度短语另外定位。未知与不适用分别编码，不能把源文选择当作无歧义形态识别或把命令许可当作实际执行。该试样为同一助手依据已知教材有意选例，非自然随机样本、金标准、独立复核或准确率试验；未接RAG或学生池。
