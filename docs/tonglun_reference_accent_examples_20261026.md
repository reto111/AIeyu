# 中国口音章节的例示角色与版面补证

原书这一章既有目标音、错误替代，也有纠正说明。新增资料明确保留这些角色，不把所有音标都当作推荐读音，也不把整段纠正说明标成错误。送气h、双点与重音、鼻化õ、j有无和音位竖线继续保留原转录候选，未因此全章逐符放行。
