# 通论转录的重音、音标与字符来源清点

本记录清点归档转录的字符及来源位置，不自动修改文本，也不替代原图音标审核。依据[清点002](../data/processed/tonglun_reference/reviews/unicode_inventory_20261025_002.json)和[独立实现的机械重放](../data/processed/tonglun_reference/reviews/unicode_inventory_verification_20261025_001.json)。001为较窄字符类别的历史版本，保留。

## 范围与结果

302个编号单元共602749个Unicode字符；175个ready和127个隔离均纳入本地审核清点。隔离正文未加入默认检索。各单元正文均由按页排序的审核片段直接拼接重建，未在页间另插字符。730张来源图完成指纹读取，但本任务没有新增逐图视觉审核。

| 类别 | 字符事件数 |
| --- | ---: |
| 组合附加符号 | 2462 |
| 音标修饰及扩展字符 | 118 |
| IPA区字符 | 168 |
| 上下标字符 | 236 |
| 星号及反引号 | 1777 |
| 合计 | 4761 |

这些数字是所列Unicode范围的机械事件数，不是音素、错误、调核或例句数量；同一词可以有多个事件。星号可能是非合语法标记，也可能是排版符号，未一概解释为调核。该分类不声称穷尽所有特殊字形。

## 偏移和重音处理

每个事件保留卷别、单元、原正文偏移、页片段偏移、字符名称和码位、相邻组合簇、NFC/NFD表示及上下文；页绑定另外保留PDF页码、印刷页码、页审核哈希和图像哈希。偏移按Python Unicode字符计数，不是UTF-8字节、UTF-16代码单元或PDF字形坐标。对外接程序应显式转换坐标，不能直接套用浏览器字符串索引。

7个单元若整体做NFC规范化会变化；这不表示7个错误。本清点应用修改0。原文引句入口保留重音、ё和空白；检索表示删除锐重音并忽略两种排版符号，仍区分ё/е。不得把检索表示回写为原书引文。

在俄文字母及组合符号的局部词串中，检索表示相同而原拼写不同的组共有559组，其中40组含至少两个带锐重音的不同形式。其余组也可能只是带重音与不带重音的并列出现。例：во́лос/воло́с和до́ма/дома́。559不是559对同音异义词，也不是语义冲突数；词形、语境和重音功能仍需语言学判断。

## 复核与使用限制

复核程序不导入原清点实现，从只读数据库重新读取页片段，核对302个单元正文哈希、4761个事件的字符与位置、730张图像、全部检索形式组及其样例偏移。对正文偏移、页片段偏移、字符和页绑定的4种篡改均拒绝。验证只说明产物与现有归档相符，不说明归档与原印字形全部一致，更不是独立专家判断。

该清点可用于安排复杂音标、组合符号、跨页引用及客户端偏移转换的审核优先级。后续如改动转录，须另生成版本和偏移，保留旧快照。论文中可以报告编码复杂度和可追溯覆盖，不据此报告OCR正确率、转写准确率或自然语言频率。
