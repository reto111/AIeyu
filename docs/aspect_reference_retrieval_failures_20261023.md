10次模式失败中，6次目标没有进入排序，4次目标在前5名以外。没有一次是目标已经排入前5却单独因上下文预算被略去。某些返回包确实略去了其他长节，但不能把该事实误报为预期目标漏检的原因。完整问题、查询词、前10名、实际返回节和预算略去记录见[逐题轨迹](../data/processed/aspect_reference/rag/natural_failure_trace_20261023_001.json)。

结果揭示两类不同的工程限制。未进入排序的6次中，词项模式2次没有提取到已登记词项；passage模式4次在主题词门槛提前返回，其中2次没有主题词项，另2次只有宽泛的“动词”。这4次实际仍有16–20个表面特征，不能归因为没有中文字对。存在相关排序项时，多个近邻主题又可能把预期节排到第6、9或14位。passage在这组中覆盖18/24，低于默认20/24；原算法与成绩未改。

后续另做[单门槛消融](aspect_reference_passage_gate_ablation_20261023.md)：只移除上述passage提前返回，当前93节的目标覆盖18/24→21/24，但主题重叠空证据3/8→0/8、普通无关8/8→0/8。这个已知题上的诊断条件没有成为默认入口，也没有混入原冻结成绩。

“预期目标未出现”是这里的操作性指标。预期目标由同一助手据书设计，其他返回节可能部分有用，不能据此直接判为错误回答；反过来，目标出现也不证明足以回答问题。主题重叠范围外问题另有默认空证据1/8、passage 3/8的失败，应与自然题漏检分别报告。独立相关性评分、真实用户抽样和生成答案评价仍未完成。
