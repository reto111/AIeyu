未完成体序列可在重复语境表达事件先后，但不能将任意组合一律视作先后或同时。一连串结果事件与过程环节分开：恢复一次场景时，结果事件可能用完成体，过程环节仍用未完成体。单向运动的开始义按本书特定语境转述，第三章§1有关идти的异议另录，未消除争论。反义交替与过去时条件结构也保留限制和完成体直观示例例外。

结果概括事实中的行为已结束并达到结果，与结果当前是否仍存在分属不同问题。结果取消不是词项永恒固有的意义，反向行为有时由后文另一个动词表达，或尚在进行；相同未完成体也可进入结果存在语境。努力尝试的非结果概括事实不承诺成功，但不是断言失败，成功/失败两种续接均保存。

恒常状态的回顾与同步观察依参照点区分。有限次数词也非概括事实的充分条件，本书明确排除特定时空的具体重复；例(29)的Бондарко脚注与本书归类意见并列保留。次数中立属于形式层，不能抹掉上下文明示的具体次数。
