## 数据来源与用途

本研究以张家骅《现代俄语体学》第2版（高等教育出版社，2004）为理论参照，建立保留原始转录、来源页码与编校轨迹的本地知识库。扫描PDF共481页；正文理论材料划分为100个知识单元，绑定正文414个PDF页。前置材料、练习、原书答案及书目另行保存，60个非理论单元不进入理论检索。扫描书是教学专著，其例句属于经作者选取的教学材料，不能直接作为自然语言使用频率的代表性样本。[来源与使用说明](aspect_reference_editorial_candidate_20261022.md)

原始转录层与模型编校候选层分别保存。原始层保留40个ready理论单元及60个unresolved理论单元；候选版本在不改动原始表的条件下，允许显式检索40个原ready单元和48个模型编校单元，12个理论单元仍隔离。原40节正文共84,979个Unicode码点，48节候选正文共235,039个码点，可取正文合计320,018个码点。字符统计包含空白、引例和脚注转写，不等于汉字数、俄语词数或模型token数。[逐节规模与指纹](../data/processed/aspect_reference/reviews/corpus_profile_20261022_001.json)

同一页可能包含不同状态的片段。414个正文PDF页中，342页所绑定的理论片段均可取，14页同时含可取与隔离理论片段，58页仅绑定隔离理论片段。这里的“均可取”描述单元启用范围，不是整页无误或字符正确率。PDF39的墨迹遮挡仍保留占位并隔离，不能根据上下文补字。

## 编校与可追溯性

每项候选编辑保存原单元键、原正文哈希、精确旧值、原偏移、新值和裁定依据。108条当前提案含115处编辑，其中99处位于48个可取候选单元，16处仍随未决单元隔离。125条原始疑点说明是一组审核记录，其中一条可能包含多个问题，不能把其条数直接视为错误数。[编校预览](../data/processed/aspect_reference/reviews/editorial_change_preview_20261022_001.md)

外部查证区分原刊扫描核图、原作电子转录、同一作者后续论文、索引线索和据原论文作出的模型推导；记录22条来源，不将不同强度证据合并为独立专家认证。教材引例与所查文学原作出现异文时保留教材原值并标注边界。候选文本作为“编校候选层表述”引用，原书逐字引文则返回原页查核。[来源证据分层](../data/processed/aspect_reference/external_evidence/source_manifest_20261022_005.json)
