## 不能只做字符串替换的案例

дуло（树洞）若改俄文为дупло，会破坏原段“同音词形”的论证关系；当前建议保留дуло，只改中译为枪口。пустынь/пустырь也分别保留词形和释义证据，当前按保留教材词形的目标提出中文修订，不声称还原作者原意。

下册во́лос原被标为复数第一格。词典列其为单数形式；当前建议只改数标签，保留它与воло́с的重音对立。不能为了修词形把它改成волосы后，仍把该例称为仅由重音表达语法差别。

на совсем即使按词典合写为副词насовсем，也仍不能成为“前置词表达时间关系”的例项；这一项保留，无新增例句或自动合写。
