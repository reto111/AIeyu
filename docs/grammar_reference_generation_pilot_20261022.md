## 引用失败与可用性限制

冻结校验器要求每条回答主张有引用，且引句至少6个非空白字符、逐字出现在去Markdown格式后的来源中。10份RAG响应7份通过（包括1份材料不足）；9份实质回答只有6份通过。39处引用中37处逐字存在，36处同时满足最短长度。没有为了提高通过率改短句阈值、改重音或重写回答。

1. P01引用“通常属中性”仅5字；内容存在但不满足原定长度。
2. P08第三条为明确标注的一般知识、引用空数组，符合本次可选资料实验提示词，却不符合部署检索入口的“每条主张有证据”契约。这是两个契约的边界差异，不能冒称全部生产可用。
3. P09把来源的`сказа́ла`引成`ска́зала`，另一引句还保留了Markdown星号，与冻结校验器去格式的引用规则不符。解释中的依附关系正确，逐字引用仍判失败。

逐字存在也不等于语义充分支持。P03第三条列出所有格形式，但其唯一引句只讲сорок重音；P06第二条讲性数及词尾，但引句仅说不分人称、分性数；P01扩展例、P02扩展示例的引句没有覆盖全部例名。这些内容能从整节另找支持，却不能把现有引用当作逐项充分。生产使用应阻止引用失败回答直接展示；本轮保留原始失败，不再追加生成修复请求。

P04的原书“第一、四格重音在词干”是简化表述，第四格同第二格时需结合表格、动物性等条件解读。本次据书覆盖评分不替代独立规范评议。26/26是少量预设要点覆盖，**不是答案正确率100%、全书正确率、专家盲评或显著效果证明**；无RAG组也有核心正确答案。题目、金标准与评分均由同一助手制定和复核，样本含本书特定任务，论文中必须披露。
