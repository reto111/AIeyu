# AIeyu 作品集说明

更新：2026-10-27。公开展示内容以此页及 Demo 为入口；详细研究记录见 CURRENT_STATE.md。

## 可直接用于作品集的项目描述

AIeyu 是面向俄语专四、专八的个人自适应备考助手。项目将诊断、组卷、判分、中文错因解析、能力画像、薄弱项训练、错题复习和词汇学习组织成闭环，帮助学生知道错在哪里、为什么错以及下一步练什么。

系统沿用 Python、SQLite 与静态网页架构，提供账号隔离和学习记录管理，正式 AI 讲解使用 DeepSeek 接口。内容侧采用来源绑定、审核状态、隔离机制和可重放修正，保留原始材料与编校层的差别；更新数据库前备份，避免覆盖学生记录和后续人工修订。

并行研究包括语法、《新时代俄语通论》和现代俄语体学知识库，探索检索、页级引句定位、主张语境回查与证据检查。研究指标与产品能力分别陈述：检索命中、引文存在、语义支持和学习效果是不同层面的评价。

- `preview.png`：学习中心封面，适合作品集缩略图。

- `PROJECT.md`：本项目介绍。
- `MANIFEST.json`：附件文件大小与 SHA-256。

演示路线：开始三题 → 选择并提交 → 查看中文解析 → 练习薄弱点 → 返回学习中心 → 翻阅词卡 → 查看项目说明。

本次附件实测：在临时 Edge 浏览器中禁用网络，直接打开 HTML 文件；完成判分、错题、巩固、词卡与重置流程，检查键盘入口及 1440 / 390 / 320 像素宽度，未发现横向溢出或脚本错误。截图来自该离线 Demo，非生产服务器截图。

## 能力与边界

| 层面 | 当前进展 | 展示边界 |
| --- | --- | --- |
| 学生产品 | 注册、登录、专四/专八组卷、自动判分、错题与词汇复习、AI 解析接口 | 本次不部署服务器、不测试真实付费接口 |
| 离线 Demo | 原创基础样例、实际判分、按错题选择巩固方向、词卡队列 | 独立展示界面，不是完整生产界面；静态解析、不保存账号、不调用 AI |
| 语法研究 | 368 节编校研究版；10 题双组共 20 次生成对照已有记录 | 开发期小样本，非独立盲评；不能当总体正确率 |
| 通论研究 | 302 单元，175 ready、127 隔离；候选研究快照另存 | 研究纳入不代表原隔离解除；整体审核未完成 |
| 体学研究 | 原始、编校候选与隔离层分开；例句范围、主张语境回查 | 尚有主张语境待补核，独立复核未完成 |

以上研究数值依据 2026-10-27 本地进度文档，不代表本次重新审核全部教材，也不代表当前生产服务器状态。

## 仓库与复现

当前开发分支：[codex/tem4-clean-rebuild](https://github.com/reto111/AIeyu/tree/codex/tem4-clean-rebuild)。Demo 源码在 `apps/portfolio_demo/`，用 `python scripts/build_portfolio_demo.py` 重建 `dist/portfolio/AIeyu-portfolio-demo.zip`。

GitHub 保存代码、测试和进度文档；`.env`、数据库、教材 PDF 和 `data/processed/` 研究产物不随仓库上传。详细研究文档引用的本地证据链接在 GitHub 上可能不可访问，依赖这些材料的测试需要本地数据。离线 Demo 自身不依赖这些材料。
