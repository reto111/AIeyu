复核：про Джек Лондона 的名应变为 про Джека Лондона；另作者不是先前猜的 В. Каверин。已找到同句原刊《Новый мир》1976№5第116页，页眉为 ЛАЗАРЬ КАРЕЛИН，目录也列该作者，故署名改 Л. Карелин。

依据：[《Новый мир》1976年第5期，目录及印刷页116](https://imwerden.de/pdf/novy_mir_1976_05__ocr.pdf)；书内上下文；模型编校判断
