# passage主题词门槛的单项消融

本实验在已知的冻结50题上，只移除passage排序前的一道主题词门槛。它是观察到漏检后进行的诊断实验，不是独立留出评测，也没有据结果继续调参或改默认入口。协议先写出，再运行对照；[协议与指纹](../data/processed/aspect_reference/rag/passage_gate_ablation_20261023_001_protocol.json)、[完整结果](../data/processed/aspect_reference/rag/passage_gate_ablation_20261023_001.json)保留。

现有passage入口先从问题取已登记的主题词。没有词项，或只有“俄语、汉语、动词、结果、语法意义”等宽泛词项时，入口直接返回空。它在这一步尚未对中文字对特征进行排序，因此“可提取表面特征”与“进入排序”是两件事。这解释了旧漏检轨迹中部分问题明明有16–20个表面特征，却没有候选排名的现象。

消融仅删除该处提前返回，保留查询特征、权重、700字符窗口与100字符重叠、排序融合、前5节、40000字符预算、来源状态与引用校验。原检索文件、候选包和50题均未改；运行时在独立命名空间替换一个函数，不覆盖默认函数。门槛原本允许的或明确指定源节的70个包逐字段一致。另有15题在两种来源范围中原本被该门槛拦截。

|来源范围与指标|原passage|移除门槛|
|---|---:|---:|
|原40节：自然24题目标覆盖|6/24|9/24|
|原40节：主题重叠范围外空证据|3/8|0/8|
|原40节：普通无关空证据|8/8|1/8|
|当前93节：自然24题目标覆盖|18/24|21/24|
|当前93节：主题重叠范围外空证据|3/8|0/8|
|当前93节：普通无关空证据|8/8|0/8|

当前93节的目标覆盖增加3题，但11道原本返回空的范围外题开始取得教材来源：3道主题重叠题和8道普通无关题。来源仍通过当前状态与逐字引用校验；这表明“引用来自允许节”不能替代“材料足以支持该问题”。本实验没有生成答案，不能将这些来源包直接计为错误回答。

明确指定源节的10题在当前实际范围下，两种方案均10/10符合；其原先10条隔离预期中，3条已因出处证据成为合法候选，因此保留原预期与当前范围两种记录。移除主题词门槛没有解除7节理论隔离。

结果不支持直接删除门槛并默认化。后续方案应同时报告合法自然题漏检和范围外取证。这些对照仍由同一助手在已知题组上完成，尚无独立相关性判读或生成评价。原冻结成绩18/24及20/24继续保留，21/24必须标为这个特定消融条件下的开发性结果。

运行方式（输出路径必须是新文件）：

```powershell
.venv/Scripts/python.exe -X utf8 scripts/aspect_passage_gate_ablation.py --output data/processed/aspect_reference/rag/passage_gate_ablation_NEW.json
```

该命令只读本地候选，写诊断协议和结果；不调用生成API，不修改RAG默认入口。
