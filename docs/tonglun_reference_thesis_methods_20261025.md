# 《新时代俄语通论》可追溯检索研究：方法与阶段结果底稿

本稿供论文前期设计和材料整理使用，数据截止2026年10月25日补证候选009。已建成可重放的原转录来源与本地检索基线，正式编校研究版、独立问题评价和生成对照尚未完成。本稿中的知识资源是语言学教材文本，不能直接称为自然俄语使用频率的代表性语料库。

## 研究对象与问题

研究对象为用户提供的《新时代俄语通论》上下册本地PDF。初步研究问题是：在保留卷别、单元、页码和原转录的条件下，能否建立可复核的检索来源；自然问句与手给关键词的检索表现如何；隔离有疑点的内容能阻止哪些来源误用，又留下哪些与问题范围有关的误取证风险。

研究不预设教材全部正确。转录忠实度、教材自身疑点、编校建议、检索目标命中、引文逐字存在和引文充分支持回答分别记录，不能用某一层的通过替代其他层。

## 字符与编校证据

[字符清点](tonglun_reference_unicode_inventory_20261025.md)覆盖302单元602749个字符，登记4761个选定特殊字符事件；均可回到页片段，包含组合重音和音标等。原文保持重音和ё，检索表示与引用表示分开。559个归并组含不同拼写，其中40组有至少两种带锐重音形式；这些是编码清点，不是语义分类结果。

[补证候选009](../data/processed/tonglun_reference/editorial_candidates/evidence_preview_20261025_009.json)覆盖73条原待核记录：58项建议共65处编辑，14项仍待证，1项撤回局部误报；其中11项只处理一部分组件。其余66条未由这一补证系列处理。实际应用0；全部139条原待核状态保留。覆盖记录数不能写成纠正错误数，局部补证不能写成整条解决。

证据按书内对齐、公开规范词典核图、学术电子转录、原作署名、网页索引节选和同一助手的译文建议分别说明。例如，《俄罗斯语法》§1658及§2725支持сквозь支配第四格，同时支持其副词来源分类，因此只建议改配格代词；§1435出现исписать все чернила，反而支持保留这一教材例词。后者说明保留和撤回误报同样属于质量控制结果。

当前公开词典是旁证，不一概代表教材出版当年的规范。网页HTTP失败不报告为下载成功，电子转录不报告为纸本核图，词典未命中不报告为词不存在。所有判断仍缺独立专家审核；不能报告人工金标准正确率。

## 检索实验与指标

现有默认入口使用显式关键词。另建固定的自然问句候选入口，利用302个单元标题构造检索词汇，只检索175个ready正文。该候选包含汉语最长匹配、俄语整词与连字符变体处理、词频权重及标题和正文得分，未引入词形还原、向量数据库或外部生成。

[冻结协议](../data/processed/tonglun_reference/rag/question_protocol_20261025_001.json)先保存代码和来源哈希再执行，共150个正例开发问题、8个普通无关问题和8个主题重叠范围外问题；另检查127个隔离目标。正例由开发助手基于已知教材和目标单元编写，两种输入分别为手给关键词与自然问句，输入信息不对称，不能据结果宣称某一算法全面优于另一算法。这组问题没有被用来在本次结果后继续调参。

目标命中@k定义为预定单元出现在返回前k个来源中。空返回率是整道问题无来源返回的比例；它与某个特定隔离目标未返回是不同指标。现有目标标注由同一助手给出，没有证明唯一性或排除等价来源。

## 后续研究的必要条件

正式评价应先冻结研究问题、来源版本和评分规则，再由未参与检索实现的人编写问题、核定允许来源，并保留无答案和主题重叠问题。开发集与独立评价集按来源单元或章节分开，避免仅换问法复用同一目标；多来源问题允许多个有效来源组合。应报告每编覆盖和未测试部分，不只合并总分。

检索评价之后还需分开评来源相关性、来源充分性、引文逐字可定位性、回答主张支持度及拒答恰当性。两位评阅人的原始评分、分歧和裁定分别保存；未评分留空，不补成0。若开展生成对照，需另有明确服务商、外发内容范围和调用预算，不能沿用其他书已经耗尽的授权。

若论文转向例句语料研究，还须完成俄汉例句边界、署名、引用层次、重复和跨页对齐，区分作者论述、构造例句与文学摘引。当前编号单元和词串清点不能替代这些标注，也不能直接支持俄语语体现象的频率结论。

## 可复现范围

已可复现的是来源指纹、审核状态、候选编辑重放、原转录检索、固定问题目标命中、隔离目标不返回和局部引句定位。现有19项相关测试及来源快照篡改拒绝是工程证据。未修改学生库、其他书库和原PDF；未部署或调用收费OCR、生成服务。正式论文应保持这些边界，并将后续新数据与本稿版本分列。
