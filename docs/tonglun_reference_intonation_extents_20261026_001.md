# 调型1、2的整例边界

[本地研究包](../data/processed/tonglun_reference/layout_candidates/intonation_extents_20261026_001/README.md)已核PDF293—295的两单元全部18组用法，共59个印刷例示：调型1为28，调型2为31。95个调型标签和92对转录星号各绑定到一个整例；这三个数字口径不同，不据此推算调核数量或发声次数。

整例保留规则说明的原转录锚、正文起止、原页及旧语调索引ID。两例跨页：Василий Николаевич例从293接294，Максим едет例从294接295。墨迹遮挡的主语保留占位；不从另一个相似例句补字。

“Познакомьтесь; /Это Нина”保留为同一例示；询问Нина英语能力及其答话保留为一个问答对，不按句号或问号数自动拆例。标题、称名句、祈使句、复合句都按书中例示边界记，不统一冒称完整陈述句。

[边界重放](../data/processed/tonglun_reference/reviews/intonation_extents_verification_20261026_001.json)通过59例、18组、95标签、92星号及4有效裁片像素，拒绝漏跨页、补主语、重复标签、伪造ready、伪造调核认证、截断对话及混入规则标题7类变化。初稿293裁片底边过近，封存前扩下30像素；弃用裁片和修正记录保留，不作完整行证据。

包内read_examples.py只用标准库。默认返回空列表；显式--research-isolated才读取这批隔离材料。只去配对转录星号，保留大小写、ё与组合重音，分别回传整例页和命中短引句页。[CLI实跑](../data/processed/tonglun_reference/reviews/intonation_extent_reader_verification_20261026_001.json)在-I进程通过：默认0结果，开启后跨页例1个结果，短引句仅在第一页。初跑Windows默认GBK不能输出组合重音，已显式设置UTF-8并复测；-I不是操作系统文件沙箱。

本批核的是全部例示边界，未认证全部印刷字形、完整斜体范围或调核音节。原两单元仍unresolved，不改全书175默认检索、139原待核及既有实验成绩；独立专家复核0。603标签完整索引仍为旧版，仅这95个标签本批增补整例范围；其余508标签尚无本系列整例边界记录，不等于还有508个例句。
