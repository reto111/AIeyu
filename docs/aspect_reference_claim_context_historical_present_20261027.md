重复解释可由词义、次数词和句法关系提供线索，不要求三因素每句同时出现。主体的泛指读法与单复数形式分开；不能见复数就排除一次具体过程。现在时更多用于概括重复和性质说明，是本书的定性意见，未做自然语料频次对照。

历史现在时通过现在形式与过去上下文的反差提供修辞效果，同时可作为作者话的叙事方法，效果并非总同样明显。客观事件可以有界，但本书认为该未完成体用法对界限中立；这种理论分析不扩到未完成体的所有用法。恢复过去叙述时，有界结果、状态、未达界限及重复要分别处理，不能统一逐词换体。

历史现在时及其与其他体时形式混合可表达不同时间关系。与具体事实完成体过去时组合可突出事件，与结果存在完成体过去时组合则可表示持续行为与结果状态同时并存，不自动是先后。例号10/11候选和теребит字形候选保持，不回写原印。
