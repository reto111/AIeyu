# 论文数据与方法口径底稿：91节版本

本底稿对应[候选006与编号索引004](aspect_reference_research_progress_20261022_003.md)，用于后续论文写作；不代替独立专家或导师验收。

本研究将张家骅《现代俄语体学（修订本）》作为俄语体范畴的理论和教学引例资料来源，建立与原页绑定的检索知识库。该资料属于教学专著，书内例句受到作者的选例、节略和编排影响，因此不将其作为自然语言使用频率的代表性样本，也不根据书内引例数量推断俄语体形式的自然分布。

原印转录层保留471页记录、135个审核批次和40条历史页修订，包含100个理论单元及60个练习、答案、书目或前置单元。理论原印层40单元ready、60单元unresolved，状态保持不变。在此之外建立独立的编校候选层。当前候选006允许40个原ready单元与51个明确标记的模型编校候选单元，另9个理论单元继续隔离；60个非理论单元不进入理论检索。

编校方案保留旧值、新值、稳定来源键、原单位偏移及原页绑定，通过同时应用原偏移重建候选正文。当前114条提案含123处修改，其中110处进入允许候选单元，13处仍随未决单元隔离。原40个ready单元正文没有编辑。原125条疑点说明中的108条形成方案、8条保守保留、7条待文学来源、1条理论/语境未决、1条墨迹不可辨；另外6条追加记录单列，不混入125的分母，一条记录亦可能包含多个问题。修改来源包括原刊扫描、电子转录、同作者后续论述和模型中文判断，不将这些证据层级合称为专家认证。

为支持例句定位，研究进一步抽取以括号数字起段的段落锚点，构成1453条编号锚段索引。该数量包括269条原ready、1028条候选和156条隔离记录；启用候选后允许查询1297条。锚段按空行结束并附邻近上下文，可能是多句、公式或对话第一段。无编号、行内、表格和练习答案例句不在计数范围，完整例句边界与俄汉逐句对齐未完成，故不将1453解释为全书例句总数、俄语句数或自然语料句数。

检索采用本地SQLite及可重放的词项排序；可选段落模式加入中文字符对和俄文词特征，保持隔离约束与整节上下文预算。评价分别报告预定来源是否实际进入上下文、该来源是否在当前允许范围、无关问题是否空证据，以及隔离材料是否拒绝。原32道开发题曾用于改进检索，其32/32结果不作为独立留出表现。随后冻结的50题中，24道自然题在候选90初次执行时，默认词项模式为20/24，段落模式为18/24；8道含主题词的范围外问题分别仅有1/8与3/8返回空证据，表明主题重叠仍会导致非相关取证。该结果是检索行为，而非已生成答案的语义错误率。所有题组均由同一助手依据已知资料编写，不能当作独立盲评或真实用户样本。

工程验收覆盖当前候选100单元的精确重建、原表逐行一致、91允许单元的引句检查和篡改拒绝，以及9理论与60非理论单元的隔离。编号索引全量验证1453条原文片段、编校重放、原页与上下文绑定，另对19条预先选定样本查看23个PDF原页。这些检查证明限定范围内的可追溯性和工程约束，不证明全书逐字或语义正确率100%。当前允许正文337298个Unicode码点，计算单位包含空白、引句和脚注，不能换算为俄语词数。全书引用出处核验、逐例语义标签、独立专家审核及有无RAG的生成对照实验仍待完成。
