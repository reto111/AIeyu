01 / 产品

从一次作答，走向持续训练

现有学生端包含注册登录、按来源组卷、阅读成组、自动判分、错题本、中文解析与追问、薄弱项训练和词汇复习。低样本保留不确定性，避免把短暂失误当成确定能力。

02 / 技术

Python + SQLite + 静态前端

账号隔离、学习历史与审核证据放在现有轻量架构中。正式 AI 解析使用 DeepSeek 接口；内容修改采用备份、事务和稳定来源键，避免覆盖人工修正。
