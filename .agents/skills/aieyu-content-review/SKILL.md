# AIeyu 内容审核

执行权限、澄清和完成要求统一见项目根目录 `AGENTS.md`，不在此重新定义批准流程。

## 核验方法

1. 确认本次考试、年份、题号/词条范围、输入文件和数据库。记录总量、完成量及未决项；历史状态不替代本次覆盖证据。
2. 先检查 PDF 文字层。可复制页优先直接提取；扫描页 OCR 后对照原图。混合 PDF 按页选择，不能因某一年扫描就给其他年份全部 OCR。
3. 题目检查题干、填空位、四个选项、答案来源和文章绑定。按版式识别选项，注意姓名首字母被当作选项、跨页页眉进入选项，以及罗马数字被当作西里尔字母。
4. 阅读以整篇核对起止边界、缺段、跨页断词和所属全部题目；选择题审核完成不能代表文章已审核。仅凭语法通顺不能推定复原正确。
5. 词汇逐项对比词头、词性与中文核心意义；`е/ё`、`о/б` 仅作局部有依据修正。移除混入词义的性/体等标记和无法识别的非必要例句，不能丢弃核心义项或靠回译一致宣称正确。必要时查可靠词典并记录来源。
6. 水印处理仅作用于临时副本；去水印或二值化可能同时抹掉标点、下划线、字母，存在歧义时回看原始彩色/灰度页。保留原 PDF。

## 写入与证据

- 修正候选保留原值、新值、稳定来源键、原页位置和理由。模型预测无法得到证据支持时保留待审核，继续处理其他项，最后合并未决清单。
- 题库清洗权限不能推导为开放用户暂缓题目。AI 生成题与真题分别保留来源；新生成题默认草稿，按已约定人工审核标准发布。
- 写入前做只读差异预览和一致性备份，事务提交；旧值不匹配时列为冲突，不能用旧补丁覆盖后续人工修正。用考试+年份+原题号等来源信息核对，不能假设两台机器内部 ID 一致。
- 审核日志保留当时决定，不按题目现状批量重写历史；纠正记录采用可追踪的追加说明。纯正文修正不得冒充审核通过。
- 验证关联数量、四选项、答案对应、完整性和幂等性；核对实际审核范围。报告规则命中数与人工/视觉覆盖量分别列出，零告警不能表述为零错误。
- 在授权批次范围内连续执行，不每批询问“是否继续”。真正未决内容单列，其余已核验内容按原授权落地。
